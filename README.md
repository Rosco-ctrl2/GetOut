# GetOut

Organizza il materiale di lavoro dentro valigie, zaini e flight case: vista 3D, ricerca, pezzi,
scorte da riordinare, prestiti con promemoria WhatsApp, import/export Excel.

**Versione attuale: 1.2.5.0**

## Scarica e installa

| Sistema | File | Come si installa |
|---|---|---|
| Windows 10/11 | [GetOutBeta.Setup.zip](https://github.com/Rosco-ctrl2/GetOut/raw/main/download/GetOutBeta.Setup.zip) | Estrai lo zip, doppio clic su `GetOutBeta.Setup.exe`. Se compare "Windows ha protetto il PC": *Ulteriori informazioni › Esegui comunque*. |
| Mac (macOS 10.10 e successivi) | [GetOutBeta.Setup-Mac.zip](https://github.com/Rosco-ctrl2/GetOut/raw/main/download/GetOutBeta.Setup-Mac.zip) | Apri lo zip, doppio clic su `GetOutBeta.Setup.dmg`, poi su *GetOutBeta.Setup* › *Installa*. Se è bloccato: *Impostazioni di Sistema › Privacy e sicurezza › Apri comunque*. |

## Aggiornamenti
GetOut si aggiorna da solo: all'avvio controlla questa pagina e scarica la nuova versione,
che parte al riavvio successivo. I tuoi dati restano sul tuo computer e non vengono toccati.

Per suggerimenti: menu ☰ › **Dammi un Feed**.
